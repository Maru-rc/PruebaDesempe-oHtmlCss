# Shattered Riffs Web Page

## Project Description

This is a web page for the Rock Band Shattered Riffs, it contains several sections about the band like a past and comming events, a section about the band and a gallery section with diversus photos, also a footer with the band social media and some of their best songs.

## Technologies used

### -HTML5
### CSS3
